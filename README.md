# Naesara Sunworks

A responsive, single-page holding site for Naesara Sunworks, featuring solar products and services, general IT solutions information, and direct contact links.

## Run locally

```sh
npm install
npm run dev
```

## Validate and build

```sh
npm run lint
npm run build
```

The page uses the existing Vite, React, and TypeScript setup. Its solar illustration and brand mark are local SVG assets; the layout does not rely on external image services.
